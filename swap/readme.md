# Swap Tracker 📊

A lightweight, high-performance monitoring toolkit designed to capture, log, and visualize system-wide memory metrics, Docker container memory/swap usage, and granular process (PID) swap breakdowns.

---

## Features

* **Ultra-Lightweight Logger**: Executes in under **0.2 seconds** and consumes less than **4 MB of disk space** per week when run every 5 minutes.
* **Interactive Dashboard**: A single, static HTML file powered by **Apache ECharts** with zero heavy server-side dependencies.
* **Granular Visibility**: Tracks system memory, individual Docker container cgroups, and process-level swap usage simultaneously.

---

## Directory Structure

```text
/opt/swap-tracker/
├── log_swap.sh         # Lightweight cron logger script
├── swap_history.jsonl  # JSON Lines log file generated by the logger
└── index.html          # Interactive ECharts dashboard

```

## Installation & Setup

### Part 1: The Lightweight Cron Logger (`log_swap.sh`)

This script captures system memory metrics, Docker container stats, and individual process swap breakdowns, appending a compact JSON line to the history file.

1. Create the directory and assign ownership:
```bash
sudo mkdir -p /opt/swap-tracker
sudo chown $USER:$USER /opt/swap-tracker

```


2. Create and populate the script file:

### Part 2: The Interactive Dashboard (`index.html`)

The static dashboard fetches `swap_history.jsonl` dynamically and renders interactive visualizations using Apache ECharts.

#### Dashboard Capabilities:

* **Click-and-Drag Time Zoom**: Highlight any spike over a 72-hour window to zoom in down to the exact 5-minute interval.
* **3 View Modes**: Switch easily between:
1. *Container Cgroup Swap* (Stacked Area or Line)
2. *Container RAM vs. Swap*
3. *Granular Process (PID) Breakdown* (e.g., tracking specific services like `kit_spare` or `frigate.process`)


* **Deep Inspection Table**: Click any point on the timeline to freeze the view and display an exhaustive table of every container and process in swap at that exact timestamp.

### Part 3: Automate the Cronjob & View Anytime

1. **Configure the Cronjob**:
Since the logger requires root privileges to read all `/proc/PID` folders cleanly, add the job to the root crontab. Run:
```bash
sudo crontab -e

```


Add the following line at the bottom to record a snapshot every 5 minutes:
```cron
#python3 -m http.server 8000 --directory /opt/swap-tracker
*/5 * * * * /opt/swap-tracker/log_swap.sh

```


2. **Serve the Dashboard (Optional)**:
You can easily serve the tracker directory locally using Python:
```bash
python3 -m http.server 8000 --directory /opt/swap-tracker

```


Open `http://<your-server-ip>:8000` in your browser to view the interactive dashboard.
